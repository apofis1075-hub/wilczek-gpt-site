# Wilczek — publiczna strona

To repozytorium zawiera wyłącznie opublikowane pliki strony **Wilczek — dom na skraju lasu**.

Źródłowy projekt i materiały robocze pozostają w prywatnym repozytorium `wilczek-gpt`. Zawartość tego repozytorium jest publiczna i może być publikowana przez GitHub Pages.

Pliki są synchronizowane z prywatnego projektu po skonfigurowaniu automatycznego wdrażania. Nie umieszczaj tutaj sekretów, tokenów, prywatnych notatek ani konfiguracji agentów.
